# Timar AI MCP Server

A thin Model Context Protocol (MCP) server that exposes Timar payment, payout, and balance APIs as MCP tools for AI assistants.

## 🎯 What This Is

This server acts as a bridge between AI coding assistants (like Claude Desktop, Cursor, Cline) and Timar's public APIs.

**It is:**
- An MCP server (stdio transport, no deployment needed)
- A configuration adapter
- An authentication adapter
- A capability router

**It is NOT:**
- A payment engine
- A business-rule host
- A replacement for Timar's public APIs

## 🌍 Supported Languages

The setup wizard supports 3 languages:

| Language | Code |
|----------|------|
| 简体中文 | `zh-CN` |
| 繁體中文 | `zh-TW` |
| English | `en` |

## 🛠️ Supported Tools

| Tool | Description |
|------|-------------|
| `payment.create` | Create a new payment order |
| `payment.get` | Get payment order details |
| `payment.cancel` | Cancel a payment order |
| `payout.create` | Create a new payout order |
| `payout.get` | Get payout order details |
| `balance.list` | List balances for all currencies |

## 📋 Prerequisites

- Node.js 22+ (recommended) or 20+
- Timar merchant account with API credentials
- MCP-compatible AI assistant (Claude Desktop, Cursor, Cline, etc.)


## ⚙️ Configuration

### Interactive Setup Wizard (Recommended ✅)

```bash
npm run setup
```

Guides you step by step: choose language → choose environment → enter domain, API Key, Secret Key → auto-save.

### Manual Configuration (Advanced)

If you prefer to create the config file manually:

```bash
cp config/runtime.config.example.json config/runtime.config.json
# Edit config/runtime.config.json with your credentials
```

#### Config File Format

```json
{
  "language": "zh-CN",
  "defaultEnvironment": "sandbox",
  "environments": {
    "sandbox": {
      "baseUrl": "https://sandbox-api.timar.io",
      "apiKey": "your-sandbox-api-key",
      "secretKey": "your-sandbox-secret-key",
      "timeoutMs": 5000
    }
  }
}
```

**Fields:**

| Field | Required | Description |
|-------|----------|-------------|
| `language` | Yes | Interface language: `zh-CN`, `zh-TW`, or `en` |
| `defaultEnvironment` | Yes | Default environment: `sandbox` or `production` |
| `environments.<env>.baseUrl` | Yes | API base URL |
| `environments.<env>.apiKey` | Yes | API key |
| `environments.<env>.secretKey` | Yes | Secret key |
| `environments.<env>.timeoutMs` | No | Request timeout in ms (default: 5000) |

## 🔌 MCP Client Integration

> 💡 **Tip**: After running `npm run setup`, the wizard will automatically generate the configuration code below — you don't need to write it manually.

### Claude Desktop

Config file location:
- macOS: `~/Library/Application Support/Claude/claude_desktop_config.json`
- Windows: `%APPDATA%\Claude\claude_desktop_config.json`

```json
{
  "mcpServers": {
    "timar-ai": {
      "command": "node",
      "args": ["/absolute/path/to/TimarAIMCP/scripts/start-stdio-server.mjs"],
      "env": {
        "TIMAR_MCP_CONFIG": "/absolute/path/to/TimarAIMCP/config/runtime.config.json"
      }
    }
  }
}
```

## 🔒 Security

- **Never** commit your config file with real credentials
- **Never** share your `secretKey` with anyone
- The server signs requests internally - you don't need to worry about signing
- Use sandbox environment for testing

## 🐛 Troubleshooting

### "No configuration found" on first start

Run the setup wizard:
```bash
npm run setup
```

### Server won't start

- Verify your config file exists at `config/runtime.config.json`
- Check that all required fields are filled (baseUrl, apiKey, secretKey)
- Re-run `npm run setup` to regenerate

### Tools return errors

- Verify the environment (sandbox/production) matches your credentials
- Check that the API keys have the necessary permissions

### MCP client can't connect

- Verify the absolute path to `start-stdio-server.mjs`
- Check that Node.js is in the client's PATH
- Try running the server manually to see if it starts
