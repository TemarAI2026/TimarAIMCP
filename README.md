# Timar AI MCP Server

A Model Context Protocol (MCP) server and X402 payment protocol adapter for Timar payment, payout, and balance APIs.

## 🎯 What This Is

This project provides **two modes** of accessing Timar APIs:

| Mode | Transport | Use Case |
|------|-----------|----------|
| **MCP Server** | STDIO | Local AI assistants (Claude Desktop, Cursor) |
| **X402 Adapter** | HTTP | AI Agents paying per call with stablecoins (USDC) |

**It is:**
- An MCP server (stdio transport, no deployment needed)
- An X402 protocol adapter (HTTP server, pay-per-use API)
- A configuration and authentication adapter
- A capability router

**It is NOT:**
- A payment engine
- A business-rule host
- A replacement for Timar's public APIs

## ⚙️ Configuration

### Interactive Setup Wizard (Recommended ✅)

```bash
npm run setup
```

Guides you step by step: choose language → choose environment → enter credentials → configure X402 (optional) → auto-save.

### Manual Configuration (Advanced)

```bash
cp config/runtime.config.example.json config/runtime.config.json
# Edit config/runtime.config.json with your credentials
```

#### Config File Format

```json
{
  "language": "zh-CN",
  "defaultEnvironment": "sandbox",
  "environments": {
    "sandbox": {
      "baseUrl": "https://sandbox-api.timar.io",
      "apiKey": "your-sandbox-api-key",
      "secretKey": "your-sandbox-secret-key",
      "timeoutMs": 5000
    }
  },
  "x402": {
    "payTo": "0xYourWalletAddress",
    "facilitatorUrl": "https://facilitator.x402.org",
    "port": 3402,
    "networks": ["base", "ethereum", "solana"]
  }
}
```

**Fields:**

| Field | Required | Description |
|-------|----------|-------------|
| `language` | Yes | Interface language: `zh-CN`, `zh-TW`, or `en` |
| `defaultEnvironment` | Yes | Default environment: `sandbox` or `production` |
| `environments.<env>.baseUrl` | Yes | API base URL |
| `environments.<env>.apiKey` | Yes | API key |
| `environments.<env>.secretKey` | Yes | Secret key |
| `environments.<env>.timeoutMs` | No | Request timeout in ms (default: 5000) |
| `x402.payTo` | X402 only | Wallet address to receive payments |
| `x402.facilitatorUrl` | No | Facilitator URL (default: `https://facilitator.x402.org`) |
| `x402.port` | No | HTTP server port (default: 3402) |
| `x402.networks` | No | Payment networks (default: `["base","ethereum","solana"]`) |

## 💳 X402 Protocol Adapter

The X402 adapter exposes Timar APIs as pay-per-use HTTP endpoints. AI Agents can pay with stablecoins (USDC) on each request — no API keys or subscriptions needed.

### Architecture

```
AI Agent (x402 client)
    ↓ HTTP request
X402 Protocol Adapter (this server)
    ↓ 402 → pay → verify → settle
    ↓ internal call
MCP Routers (payment/payout/balance)
    ↓ HMAC-SHA256 signed request
Timar Public API
```

### Starting the X402 Server

```bash
npm run start:x402
```

Or with a custom config path:

```bash
TIMAR_MCP_CONFIG=/path/to/config.json npm run start:x402
```

### X402 Endpoints

| Method | Path | MCP Tool | Price |
|--------|------|----------|-------|
| `POST` | `/v1/payment/create` | `payment.create` | $0.01 |
| `GET` | `/v1/payment/:orderId` | `payment.get` | $0.001 |
| `DELETE` | `/v1/payment/:orderId` | `payment.cancel` | $0.001 |
| `POST` | `/v1/payout/create` | `payout.create` | $0.01 |
| `GET` | `/v1/payout/:orderId` | `payout.get` | $0.001 |
| `GET` | `/v1/balance` | `balance.list` | $0.001 |

Free endpoints (no payment required):

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/health` | Health check |
| `GET` | `/v1/tools` | List available tools and pricing |

### Payment Flow Example

```
1. AI Agent sends:  POST /v1/payment/create
2. Server returns:  402 Payment Required + PAYMENT-REQUIRED header
3. AI Agent pays:   0.01 USDC via x402 protocol
4. AI Agent sends:  POST /v1/payment/create + PAYMENT-SIGNATURE header
5. Server verifies: payment via facilitator
6. Server executes: payment.create via MCP router
7. Server returns:  200 OK + result + PAYMENT-RESPONSE header
```

### Supported Networks

| Network | Chain | Asset |
|---------|-------|-------|
| Base | L2 | USDC (`0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913`) |
| Ethereum | L1 | USDC (`0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48`) |
| Solana | SVM | USDC (`EPjFWdd5AufqSSqeM2qN1xzybapC8G4wEGGkZwyTDt1v`) |

## 🔒 Security

- **Never** commit your config file with real credentials
- **Never** share your `secretKey` with anyone
- The server signs requests internally — you don't need to worry about signing
- Use sandbox environment for testing
- X402 payments are verified by the facilitator before API calls execute

## 🐛 Troubleshooting

### "No configuration found" on first start

Run the setup wizard:
```bash
npm run setup
```

### Server won't start

- Verify your config file exists at `config/runtime.config.json`
- Check that all required fields are filled (baseUrl, apiKey, secretKey)
- Re-run `npm run setup` to regenerate

### X402 server fails to start

- Ensure `x402.payTo` is set in your config (wallet address)
- Install dependencies: `npm install`
- Check port 3402 is not already in use

### Tools return errors

- Verify the environment (sandbox/production) matches your credentials
- Check that the API keys have the necessary permissions
